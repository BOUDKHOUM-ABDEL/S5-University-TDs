Exercice 1 :  
On souhaite écrire une fonction compteur() qui : 
 
Initialise une variable locale n = 0, 
 
Définit une sous-fonction incremente() qui augmente n de 1 à chaque appel, 
 
Retourne la sous-fonction incremente. 
Exécutez ensuite : 
c1 = compteur() 
c2 = compteur() 
print(c1(), c1(), c2(), c1(), c2()) 
1. Quelle sera la sortie ? Pourquoi ? 
2. Modifiez le code pour rendre n accessible depuis l’extérieur sans l’utiliser comme 
variable globale.

et lambda.
