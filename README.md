# S5-University-TDs

Welcome to my **S5 University TDs** repository! 🎓

This repository contains my solutions and implementations for the practical works (Travaux Dirigés - TD) assigned during the 5th semester (S5) at the university. The exercises focus heavily on algorithmic problem solving, data structures, and Object-Oriented Programming, and are implemented in both **Java** and **Python**.

---

## 📁 Repository Structure

The workspace is organized into two main language-based directories:

### ☕ Java
Located in the `JAVA/` directory, these assignments focus on Object-Oriented Programming (OOP) concepts, class design, structured problem solving, and arrays.

* **TD 1**: Basics of Object-Oriented Programming.
  * Contains fundamental OOP concepts: `Exercice_1.java` through `Exercice_5.java`.
* **TD 2**: Advanced Class Design and Relationships.
  * `Exercice_1.java`, `Exercice_2.java`.
  * `Exercice_3/` (User Expenses Management): `Depense.java`, `Utilisateur.java`, `Test.java`.
  * `Exercice_4/` (Student Evaluation System): `Etudiant.java`, `Evaluation.java`, `test.java`.
* **TD 3**: Arrays, Text Analysis, and Interactive Menus.
  * Analysis tools: `AnalyseTableau.java`, `AnalyseTexte.java`.
  * Management models: `Etudiant.java`, `Menu.java`.
  * Exercises: `Exercice_1.java` to `Exercice_3.java`.

### 🐍 Python
Located in the `PYTHON/` directory, these assignments cover general scripting, dynamic typing, algorithmic fundamentals, data processing, and scripting.

* **TD 1**: 
  * General Python exercises: `exercice1.py` through `exercice6.py` (Covering variables, loops, conditionals, and dictionaries).
* **TD 2**: 
  * Advanced lists and algorithmic problems: `exercice1.py` through `exercice6.py`.

## 🚀 Getting Started

If you wish to explore or test any of these programs locally:

### For Java (`.java`)
1. Ensure the Java Development Kit (JDK) is installed on your machine.
2. Navigate to the desired directory, compile the file using `javac FileName.java` (or build using an IDE like IntelliJ, VSCode, or Eclipse).
3. Run the compiled bytecode using `java FileName`.

### For Python (`.py`)
1. Ensure Python 3.x is installed.
2. Navigate to the desired folder and run the script inside your terminal/command prompt:
   ```bash
   python exerciceN.py
   ```
